# Lotto Number Generator

## Overview

This project is a simple web application that generates random lottery numbers. It's built using modern web standards, including Web Components, to create a modular and reusable UI.

## Current Implementation

### Features:

*   **Lottery Number Generation:** Generates 6 unique random numbers between 1 and 45.
*   **Web Component:** The entire functionality is encapsulated within a `<lotto-generator>` custom element.
*   **Modern Design:** The application has a clean and modern design with a responsive layout.

### Style and Design:

*   **Layout:** Centered layout with a clear and intuitive user interface.
*   **Color Palette:** A simple and clean color palette is used to create a pleasant user experience.
*   **Typography:** Clear and readable fonts are used for all text elements.
